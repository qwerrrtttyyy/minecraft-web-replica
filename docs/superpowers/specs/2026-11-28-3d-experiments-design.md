# 3D 实验功能设计

日期：2026-11-28

## 目标

在不改变默认玩法、存档兼容与既有受控实验结论的前提下，增加三个可开关的 3D 实验：

1. 3D 密度场地形生成。
2. 渲染光照优化（8 位打包顶点光照）。
3. 材质包加载器（内置预设 + 运行时导入）。

三项实验都必须在设置页可见，提供状态反馈，并允许 URL 参数覆盖。

## 全局约束

- 运行时依赖仍只有 `three`，不新增第三方库。
- 默认值保持现有行为：密度地形关、打包光照关、经典材质包。
- 方块 id、图集既有 tile 索引、网格快照契约不得改变。
- Worker 与主线程必须使用同一份生成器实现；地形参数随 `workerConfig` 传递。
- 既有存档可继续加载；实验地形只影响新生成区块，设置页提示“新建世界后生效”。
- 浏览器实景不可用时，必须报告环境限制，不能把未实跑项说成已验证。

## 架构

### 1. 3D 密度场地形

接入点：`src/world/generator.ts`。

- `TerrainOptions` 新增可选 `densityTerrain?: boolean`，默认 `false`，因此既有构造调用与 Worker 配置无需改签名。
- `DefaultGenerator` 新增两个 3D 密度噪声实例，并由 seed 决定。
- `stageColumns` 在布尔开关开启时对近地表体积做密度雕刻：
  - 保留每列 `height` 顶面，确保现有树木 / 花草仍有稳定落脚点。
  - 在顶面下方 3~12 格用 3D fBm 打开洞穴与悬挑。
  - 在陡坡顶面上方 2~8 格用密度阈值生成岩檐 / 岩桥，形成非 2.5D 轮廓。
  - 海平面以下及水下地层不做雕刻，沿用现有防空气袋规则。
- 矿石、树木、装饰、结构阶段顺序保持不变。
- 入口：
  - 设置项 `densityTerrain`，新世界生成时生效。
  - `?terrain=density` 强制开启，便于演示与实验复现。

### 2. 渲染光照优化

接入点：`src/world/chunkManager.ts`。

- 顶点光照 `aLight` 当前为 2 个 float32（天空光 / 方块光）。优化模式改为 1 个 uint8：
  - 高 4 位存天空光 0~15，低 4 位存方块光 0~15。
  - shader 解码后除以 15，与现有光照计算完全一致。
- `buildGeo` 根据当前模式写入不同属性布局。
- 运行时切换时原地转换现有几何的 `aLight` 属性，不重建区块；材质 `needsUpdate` 并改变 program cache key。
- 公开只读状态：`lightingMode`、`vertexLightBytes`，供设置页 / F3 展示。
- 入口：
  - 设置项 `packedLighting`，即时生效。
  - `?lighting=packed` 强制开启。

### 3. 材质包加载器

新增：`src/gfx/texturePack.ts`。

- 内置预设：经典、暖色、冷色、高对比。通过读取图集 tile 像素做确定性的颜色变换，再回写图集。
- `TextureAtlas` 新增：
  - `tileNames()`：列出当前 tile 名。
  - `tileImageData(name)`：读取单格像素。
  - `applyTileImages(images)`：按 tile 名回写像素并刷新纹理。
  - `resetTiles()`：按原始 painter 重绘。
- ZIP 导入：
  - 新增无依赖 ZIP 读取器，支持 stored / deflate 条目。
  - 使用浏览器 `DecompressionStream('deflate-raw')` 解压；不可用时明确报错。
  - 支持两种包结构：
    - `pack.json` / `manifest.json` 中 `{ "tiles": { "grass_top": "textures/grass.png" } }`。
    - 否则 PNG 文件名直接匹配图集 tile 名（不含扩展名）。
  - 也支持一次选择多张同名 PNG。
- 设置项 `texturePack` 只持久化内置预设；导入包只在当前会话生效，避免把大二进制写入 localStorage。
- 设置页展示当前包名、已应用 / 未匹配数量。
- 入口：
  - 设置页“材质包”循环行。
  - “导入材质包”按钮，接受 `.zip` 或多张 `.png`。

## 前端

设置页新增 `3D 实验` 分组：

- `3D 密度地形`：开 / 关；说明“新建世界后生效”。
- `8 位顶点光照`：开 / 关；显示“单顶点省 7 B”或当前模式。
- `材质包`：循环内置预设。
- `导入材质包`：文件选择 + 状态提示。
- 分组底部说明 URL 参数。

F3 调试文本追加一行实验状态，显示地形模式、光照模式、当前材质包。

## 错误处理

- 材质包 ZIP 解析失败：toast 错误，不改变当前图集。
- 某张 PNG 无法解码：跳过并计入未匹配 / 失败数量。
- 未知 tile：忽略并回报。
- 光照模式切换时没有网格：只切材质，下一次建网格使用新模式。
- 密度地形不适用于已生成区块：UI 明确提示新建世界。

## 测试

- 地形：固定 seed 下密度模式确定性、顶面存在性、存在悬挑或额外空中岩石、经典模式不受影响。
- 光照：打包 / 解包字节往返等价，量化误差不超过 1 个光照档位；模式切换转换后的数组长度正确。
- 材质包：预设变换确定性、tile 匹配、未知 tile 统计；ZIP 中央目录与文件名解析纯函数测试。
- 工程：`npm run typecheck`、`npm run build`，相关 `test:*` 回归。

## 后续修订（2026-11-28 清理）

经过实现评估，移除两项非必要设置：

- 内置暖色 / 冷色 / 高对比预设与 `texturePack` 设置删除。调色预设不是真正的材质包，且不是幂等变换。
- `packedLighting` 普通设置删除，8 位布局改为默认路径；`?lighting=float2` 仅保留为开发对照。
- 材质包导入增强为 Java / Bedrock 资源包路径、原版别名、动画纹理首帧、32/64 分辨率缩放、ZIP 安全上限、并发解码与导入序号防乱序。
- 密度地形岩檐从 `h+3` 开始，避免占用玩家头部两格；文案改为“影响之后生成的区块”。
